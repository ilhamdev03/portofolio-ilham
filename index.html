Haloo! Nama saya Ilham, seorang siswa Sekolah Menengah Kejuruan (SMK) yang sedang menempuh pendidikan di jurusan **Rekayasa Perangkat Lunak (RPL).

Sejak awal memilih jurusan ini, saya mulai aktif mendalami dasar-dasar dunia pemrograman. Perjalanan saya dimulai dari hal-hal mendasar, seperti menyusun struktur HTML sederhana menggunakan text editor Visual Studio Code, menambahkan gaya visual menggunakan CSS, hingga menyisipkan logika JavaScript agar sebuah halaman web dapat tampil lebih hidup, responsif, dan interaktif — persis seperti website yang sedang Anda buka saat ini.

Website ini merupakan salah satu portofolio sekaligus wadah eksperimen mandiri saya dalam merancang tampilan web yang rapi dan mudah digunakan. Ketertarikan mendalam saya pada bidang web development didorong oleh rasa puas saat menjalani prosesnya: menyusun baris-baris kode dari nol, lalu melihat kode tersebut bertransformasi menjadi sebuah antarmuka visual yang nyata dan bisa langsung diakses oleh pengguna. Impian saya ke depannya adalah dapat mengembangkan platform web fungsional yang benar-benar solutif dan bermanfaat bagi banyak orang.

Di luar fokus web development, proses pembelajaran saya di sekolah juga mencakup penguatan logika algoritma, pengelolaan basis data menggunakan SQL/MariaDB, serta pengenalan awal pada pengembangan aplikasi dan gim menggunakan *engine Unity.

Saya sadar bahwa perjalanan saya di dunia pemrograman masih panjang dan masih banyak hal yang perlu saya pelajari. Namun, saya percaya bahwa setiap proyek latihan, sekecil apa pun itu, adalah langkah berharga yang membentuk proses belajar saya untuk menjadi seorang developer yang lebih kompeten di masa depan.
