Halo, saya Ilham. Saya adalah seorang siswa SMK yang mengambil jurusan Rekayasa Perangkat Lunak (RPL). Di sini saya belajar dasar-dasar pemrograman, mulai dari menulis HTML sederhana di VS Code sampai memahami bagaimana CSS dan JavaScript bisa membuat sebuah halaman jadi lebih hidup — seperti website ini.

Website ini adalah salah satu bentuk latihan saya dalam belajar membangun tampilan web yang rapi dan interaktif. Alasan saya punya ketertarikan besar pada web development karena saya cukup menikmati proses mengubah kode menjadi sebuah website yang bisa langsung dilihat dan digunakan. Mudah-mudahan suatu hari nanti saya bisa membuat halaman website yang bermanfaat bagi banyak orang.

Selain itu, di sekolah saya juga mulai mempelajari logika pemrograman, database (SQL/MariaDB), serta pengembangan aplikasi dan game menggunakan Unity. Saya masih dalam tahap belajar dan masih perlu banyak berlatih di bidang web development, tapi saya percaya setiap project yang saya buat adalah bagian dari perjalanan saya untuk terus menjadi lebih baik ke depannya.
